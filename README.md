# SLIPGATE — двумерный шутер в духе Quake 1

Браузерная игра на чистом JavaScript и Canvas 2D: вид сбоку, прицел мышью,
девять стволов, четыре эпизода (24 уровня, 4 секретных и стартовый хаб), ключи, тайники,
лифты, прыжковые площадки, давилки, бездна, слипгейты и четыре босса. Графика и звук целиком
создаются кодом — в репозитории нет ни одной картинки или аудиофайла.

## Как запустить

Откройте `index.html` в браузере — сборка и сервер не нужны.

Если браузер блокирует локальные файлы, поднимите любой статический сервер:

```bash
npx serve .        # или: python3 -m http.server
```

Один самодостаточный HTML-файл (удобно переслать или выложить):

```bash
node tools/build.js      # -> dist/slipgate.html
```

## Управление

| Клавиши | Действие |
|---|---|
| A / D, ← / → | бег |
| W, Пробел, ↑ | прыжок, всплытие |
| S, ↓ | спрыгнуть сквозь платформу, нырнуть |
| Мышь | прицел |
| ЛКМ (или Ctrl, J) | огонь |
| 1–9, колесо, Q / E | выбор оружия |
| Tab (N — закрепить) | карта уровня и статистика |
| Esc / P | пауза |
| M | музыка вкл/выкл |
| ~ | отладочная панель: уровень, сложность, состояние босса, алтари, выходы |

В настройках есть громкость звуков и музыки, яркость (50–160 %: выше 100 %
поднимает тени, ниже — приглушает свет), тряска экрана, передний план (вкл/выкл)
и полноэкранный режим.

Клавиши можно переназначить: «Настройки» → «Клавиши» (выберите действие и
нажмите новую клавишу; Esc — отмена). Экран «Управление» показывает текущие клавиши.

Геймпад (стандартная раскладка, Xbox или PlayStation): левый стик — бег и
навигация в меню, правый стик — прицел, A — прыжок, RT или X — огонь,
LB / RB — смена оружия, Back — карта, Start — пауза, B — назад в меню.

На телефоне два стика. Левый — бег; толкнуть вверх — прыжок (наклон вбок с лёгким
подъёмом не прыгает), вниз — спрыгнуть с доски. Правый — прицел и огонь: коснулись —
стреляете туда, куда смотрит герой, потянули — целитесь, палец не закрывает цель.
Стреляя с телефона, герой доворачивает на монстра у линии прицела — автоприцел, как в
Quake; цель отмечается уголками рамки. Оружие выбирается касанием его ячейки в
строке состояния, по кругу — кнопкой ⇄. У правого края — прыжок, вверху — полный
экран (заодно фиксирует горизонтальную ориентацию), карта и пауза. При ранении
телефон коротко вибрирует.

Приёмы из Quake тоже работают: **рокет-джамп** (ракета под ноги), **банни-хоп**
(прыжок в момент приземления разгоняет), **разряд «Громовержца» под водой**
убивает всех вокруг — и вас тоже.

## Что внутри

- **Четыре эпизода + стартовый хаб.** Эпизод выбирается в «Новой игре», а
  сложность — как в оригинале, шагнув в один из слипгейтов хаба. Хаб — башня
  «чем выше, тем сложнее»: лёгкие врата прямо по ходу, в конце первого этажа;
  нормальные и сложные — на втором и третьем этаже, куда ведёт лестница площадок
  во дворе позади старта. Ни одни врата не стоят на пути к другим, и все они
  вплотную к стене — их не проскочить. «Кошмар» спрятан под водой: колодец во дворе. Финал каждого эпизода переходит в следующий с сохранением
  оружия и патронов. «Продолжить» в главном меню возвращает к началу
  последнего уровня с тем же оружием и сложностью. Для каждого уровня и
  сложности запоминаются рекорды: лучшее время, больше всего убитых и тайников —
  они видны в итогах уровня и при выборе уровня и сложности.

  **Эпизод 1: Измерение Доблести**
  1. E1M1 «Шлюзовой комплекс» — база, мост над водой, кнопка и решётка
  2. E1M2 «Замок проклятых» — ров, большой зал, башня, серебряный ключ
  3. E1M3 «Некрополь» — катакомбы, затопленный склеп, золотой ключ
  4. E1M4 «Жуткий грот» — слизневое озеро, биокостюм, логово шамблера
  5. E1M5 «Древний мир» — лавовая река, зиккурат, телепорт
  6. E1M6 «Дом Хтона» — босс, которого не берёт оружие. Пульты по разные
     стороны лавового озера заряжают по электроду; когда заряжены оба, разряд
     бьёт Хтона. Заряд держится недолго, так что приходится перебегать над
     озером под его огнём. Раненый Хтон поднимает лаву на берега — спасают
     уступы; в ярости он бросает залпом по три шара. Гибель Хтона — короткая
     сцена: камера уходит от пульта к озеру, по нему ползут молнии, он
     вздымается из лавы, ревёт и уходит на дно под табличку «повержен»

  **Эпизод 2: Царство Чёрной Магии** — уровни в 2–3 раза больше, по 30–40 монстров
  1. E2M1 «Застава у Врат» — ущелье, лифт на крепостную стену, надвратная башня,
     двор с колодцем в затопленное подземелье, многоэтажный донжон, мост в небе
  2. E2M2 «Затонувший храм» — неф со столпами над водой, серебряная дверь под
     водой и длинный подводный тоннель с одним воздушным карманом
  3. E2M3 «Кузни Тени» — лифты над лавовым озером, островки с ключом и
     «Громовержцем», нижний ярус литейной
  4. E2M4 «Лабиринт Костей» — пять ярусов катакомб, шахты-лестницы, сквозной
     лифт и телепорт в потайную комнату
  5. E2M5 «Шпиль Колдуна» — башня высотой 120 клеток: этаж за этажом, вылазка
     на внешний карниз за ключом и балкон на самом верху
  6. E2M6 «Чрево Матери» — Шуб-Ниггурат: её тоже не берёт оружие, а телепорт,
     ведущий прямо в неё, спит. Его пробуждает кровь её отродий — каждое убитое
     отродье добавляет заряд. С половины заряда из-под земли рвутся щупальца
     (место удара заранее светится), а когда телепорт открыт, Мать в панике
     порождает слуг чаще

  **Эпизод 3: Нижний мир** — прыжковые площадки, давилки, угри в воде, лазерная пушка
  1. E3M1 «Врата Преисподней» — коридор давилок, огненный зал, который
     пересекают по площадкам, башня площадок
  2. E3M2 «Кровавые Шахты» — три яруса шахты, клети-подъёмники, рудные
     давилки, затопленная выработка с угрями
  3. E3M3 «Цитадель Пепла» — лифты над лавовым рвом, цитадель в два яруса,
     огненные водопады с цепочкой платформ
  4. E3M4 «Бездонные Колодцы» — спуск по колодцам, подъём по площадкам в
     пещеру с ключом, подводный ход к выходу
  5. E3M5 «Храм Вестника» — зал давилок, верхняя галерея, люк под серебряный
     ключ и золотой ключ на дне бассейна с угрями
  6. E3M6 «Трон Бездны» — Вестник Бездны: его щит держат три кристалла.
     Без щита он бросается рывками сквозь арену (за миг до броска виден
     пунктир), а на 40 % здоровья призывает грозу — молнии бьют в отмеченные
     места вокруг героя

  **Эпизод 4: Измерение Древних** — острова над бездной, фантомы, стражи, финал саги
  1. E4M1 «Мост через Пустоту» — парящие острова, дощатый мост и лифт над
     провалом, храм Пустоты в два зала, святилище за серебряной дверью
  2. E4M2 «Обсерватория» — башня в пять ярусов, вылазка по карнизам внешней
     стены за золотым ключом и купол, где слипгейт ждёт на конце телескопа
  3. E4M3 «Кристальные Копи» — галерея с провалами в пустоту, штрек давилок,
     затопленная выработка с угрями и хрустальная пещера над бездной
  4. E4M4 «Цитадель Стражей» — мост со стражем, двор под звёздами с лифтом над
     провалом, донжон, большой зал с галереей и тронный зал
  5. E4M5 «Лестница в Небо» — подъём по островам, лифтам и парящей лестнице к
     небесному храму
  6. E4M6 «Кузня Рун» — финал саги. Преддверие, Мост Клятвы над бездной и
     арена из островов над Пустотой: лифты-паромы с пультами, прыжковые площадки,
     «Корона кузни» с четверным уроном. В конце моста Древний поднимается из
     бездны. Его барьер держат четыре алтаря: каждый зажигается, только если
     простоять на нём несколько секунд под огнём, и каждая руна призывает
     волну стражи. Когда барьер падает, Древний оглушён и опускается к арене. На
     половине здоровья он вытягивает силу из двух рун — их надо зажечь снова,
     затем впадает в ярость с размашистым лучом. Гибнет он в замедлении
     времени, а слипгейт открывается в центре кузни
- **Оружие:** топор, ружьё, двустволка, гвоздомёт, супергвоздомёт,
  гранатомёт (гранаты отскакивают), ракетница, «Громовержец» и лазерная
  пушка (заряды рикошетят от стен до трёх раз).
- **Монстры:** солдат, пёс, каратель, рыцарь, огр (пила и гранаты), зомби
  (встаёт, пока его не разорвать взрывом), изверг (прыжок), скраг, рыцарь
  смерти, ворог (самонаводящиеся шары), порождение (взрывается), шамблер
  (молния, вдвое меньше урона от взрывов), гаргулья (пикирует с воздуха),
  скорпион (очереди гвоздей и жало), угорь (живёт в воде и бьёт током),
  фантом (мерцает и возникает рядом с вами), страж (башенный щит держит
  удары спереди — бейте в спину, взрывами или в момент замаха).
  Каждый босс появляется под свою табличку: за дверью арены мир замирает,
  камера уходит к нему, полосы сверху и снизу — как в кино. Полоска босса
  наверху показывает, что держит его защиту (электроды, кровь для телепорта,
  кристаллы, руны) и что делать сейчас. Гибель босса идёт в замедлении с
  белой вспышкой, а стрелка у края экрана показывает путь к выходу.
  Боссы: Хтон, Шуб-Ниггурат (порождает слуг и плюётся самонаводящимися
  шарами), Вестник Бездны (летает, огненные веера, молнии, призыв слуг;
  неуязвим, пока целы кристаллы) и Древний (веера и дождь рун,
  самонаводящиеся сферы, молнии, призыв фантомов; в ярости переносится
  через арену; неуязвим, пока не зажжены все алтари).
  Монстры замечают героя, когда видят его (спереди, а вплотную — и за спиной),
  слышат или получают урон. Звук выстрела идёт по открытому пространству: огибает
  углы и проходит коридорами и открытыми дверями, но не сквозь стены. Услышавший
  монстр идёт проверить, откуда шум. Потеряв героя из виду, монстр сначала идёт
  по его свежему следу — так находит обход по лестницам и коридорам, — затем к
  месту, где видел его в последний раз. Там он осматривается, а не найдя героя,
  успокаивается, оставаясь какое-то время настороже. Монстры будят соседей и
  дерутся между собой, если заденут друг друга. Ловкие перепрыгивают провалы и запрыгивают на
  платформы, уворачиваются от ракет, гранат и зарядов лазера. Лаву, слизь и Пустоту
  монстры обходят: не спрыгивают туда к герою, прыгают через них только туда, где
  точно приземлятся (дуга просчитывается с учётом свода), летуны не опускаются к
  ним, а изверги и порождения не прыгают в атаку, если дуга кончается в лаве.
  Скинуть монстра в лаву взрывом — можно, как в Quake. Стрелки бьют на
  упреждение и держат свою дистанцию: пятятся, если подойти вплотную, и
  переминаются между выстрелами. Солдаты и каратели не стреляют сквозь своих, а
  тяжело раненные отбегают. Чем выше сложность, тем точнее упреждение и чаще увороты.
- **Сложность — ровными ступенями.** Урон, который монстры наносят за секунду боя,
  относительно «Нормального»:

  | | Лёгкий | Нормальный | Сложный | Кошмар |
  |---|---|---|---|---|
  | урон монстров | ×0,6 | ×1 | ×1,12 | ×1,25 |
  | перезарядка атак | ×1,3 | ×1 | ×0,9 | ×0,8 |
  | атаки, доведённые до конца (не сбиты болью) | ×0,85 | ×1 | ×1,1 | ×1,2 |
  | итог в бою (замер дуэлями) | ≈0,55 | 1 | ≈1,2 | ≈1,4 |

  На «Лёгком» к тому же около трети монстров меньше, засады мельче. Главный рычаг —
  урон: он делает сильнее всех одинаково. Раньше «Кошмар» ослаблял боль и ускорял
  перезарядку так, что солдат с ружьём становился опаснее втрое, изверг — в 2,6 раза,
  а огр — в 1,4; «Сложный» почти не отличался от «Нормального». Теперь у каждого
  монстра «Кошмар» — примерно ×1,3–1,6, а «Сложный» — ×1,1–1,3. Прыжки изверга, пса и
  порождения учащаются вдвое слабее атак. У боссов свои множители: залпы, щупальца
  и молнии чаще на «Кошмаре» в 1,18 раза (было в 1,8), здоровье Вестника и Древнего
  +20 % (было +40 %), электроды Хтона держат заряд 14 секунд (было 11). Отчёт по
  всем монстрам: `node tools/dev/difficulty.js` (с `--old` — старые множители).
- **Предметы:** аптечки и мегаздоровье, зелёная/жёлтая/красная броня (как в
  Quake: поглощает 30/60/80 % урона), патроны, рюкзаки с трупов, четверной урон,
  пентаграмма, кольцо теней, биокостюм. Аптечки с крестом и ручкой, коробка
  дробовых патронов, ящик гвоздей, ящик с ракетами, батарея с молнией,
  бронежилет и рюкзак нарисованы пиксель-артом со светотенью; по крышкам
  пробегает блик.
- **Кольцо теней (как в Quake):** пока оно действует, монстры не видят героя
  вовсе — ни вблизи, ни уже в погоне: тот, кто гнался, теряет героя, ищет на
  месте и успокаивается. Шум выстрела приводит монстров на место шума, но не к
  герою. Раненый монстр чует, откуда стреляли, и чуть больше секунды бьёт в ту
  точку с разбросом, а за героем не следит; самонаводящиеся шары невидимого не
  находят. Боссы видят героя и в кольце.
- **Строка состояния:** металлическая панель как в Quake. Сверху — все стволы
  картинками (выбранный в золотой рамке, без патронов — тусклый) и запас всех
  патронов, патроны текущего оружия подсвечены. Ниже три секции: броня с
  жилетом её цвета, лицо и здоровье, патроны текущего оружия. Лицо героя —
  пиксель-арт 32×32 с контуром: косится по сторонам, как в Quake, морщится и
  скалится от боли, с каждой ступенью ранения — кровь, синяк, заплывший глаз;
  под четверным уроном глаза синие, под пентаграммой лицо красное, в кольце
  теней видны только глаза. Числа вспыхивают при уроне и подборе, при смене оружия появляется
  его название, усиления показаны значками с кольцом-таймером, при малом
  здоровье по краям экрана пульсирует красное.
- **Мир:** пули, лазеры и снаряды не проходят сквозь доски платформ — ни снизу,
  ни сверху; стрелок, которому доска закрывает героя, не стреляет в неё, а
  отходит к её краю. Двери, открывающиеся ключами и кнопками, тайники (стреляйте в
  подозрительные стены или толкайте их), взрывающиеся ящики, вода с запасом
  воздуха, слизь и лава, телепорты, лифты по вызову (вертикальные и паромы над
  пропастью: встали — поехали, на остановках пульты вызова, их можно и
  подстрелить; лампы показывают, где лифт),
  прыжковые площадки (подбрасывают на 11 клеток), давилки (падают и
  расплющивают всех, кто окажется под ними) и бездна — пустота, которая
  забирает сразу и без следа, даже под пентаграммой.
- **Засады и тайники:** на каждом уровне есть ловушки — стоит взять ключ
  или подойти к выходу, и монстры телепортируются со всех сторон. Стрелки
  сидят на уступах и балконах, до которых можно добраться. Тайники выдаёт
  едва заметная трещина в стене — и больше ничего: свет, факелы и слипгейт
  закрытой комнаты не видны, пока стену не открыли. В каждом тайнике есть
  лечение. Попасть туда, откуда не выбраться к выходу, нельзя: из воды ведут
  мостки, у ям есть трамплины и ступени (это проверяет `tools/check-levels.js`).
- **Снабжение без тупиков.** После гибели у контрольной точки ключи, оружие и
  патроны, подобранные после неё, остаются при вас — уровень нельзя «сломать».
  Если оружие где-то пропущено, в начале следующего уровня оно ждёт у входа.
  Патроны у входа не лежат: они разложены по маршруту, перед стычками, а если на
  уровень пришли совсем пустым, запас тихо пополняется до минимума. Новый эпизод
  начинается со своим стартовым набором. Когда патроны кончаются совсем,
  монстры роняют рюкзак с патронами к вашему оружию.
- **После босса** на экране появляется стрелка к открывшемуся слипгейту.
- **Для больших уровней:** контрольные точки-руны (после гибели возвращают к
  последней активированной, мир остаётся как был) и карта уровня на Tab —
  открывается по мере исследования, показывает выходы, лифты и точки.
- **Герой и монстры:** пиксель-арт, собранный кодом из шарнирных конечностей
  (бедро, колено, локоть — шаг и замах честно сгибают суставы), деталей и объёмов
  с пятитоновой светотенью; у каждого тёмный контур, чтобы фигура читалась на любом
  фоне. Глаза демонов, руны стражей и трещины с лавой светятся в темноте. Наплечник
  героя окрашен в цвет надетой брони, оружие он держит двумя руками. Цвета
  берутся из той же палитры, что и стены, а облик монстров близок к классике:
  солдат с ранцем, каратель в светлой броне с силовым блоком, рыцарь в бронзе,
  бледный окровавленный зомби.
- **Картинка:** в духе шутеров девяностых. Текстуры восьми тем генерируются при
  запуске и приводятся к собственной 256-цветной палитре (бурые металлы, камень,
  ржавчина): клёпаные листы с болтами и ржавыми потёками, технопанели с решётками
  и полосами «осторожно», кладка из блоков разной ширины со сколами и трещинами,
  гравированный металл, скала со слоями и мхом, руны. У пола есть кромка (бортик,
  карниз, дёрн), у потолка — тёмный край, толща стен темнеет вглубь. Фон обставлен
  сам: трубы, пульты и кабели на базе, знамёна и окна в замке, ниши с черепами,
  паутина и цепи, сталактиты и корни в пещерах, светящиеся рунические таблички.
  Факелы с живым пламенем и искрами, лампы с сеткой и конусом света, порталы в
  металлической рамке или каменной арке. Освещение «запечено» с тенями от факелов
  и ламп, есть динамический свет от вспышек и ракет, жидкости волнуются, небо —
  два слоя облаков или звёздное небо Пустоты. На горизонте у каждой темы свои
  силуэты в два слоя с параллаксом: трубы, мачты и краны базы с огнями в окнах,
  замки с башнями, скалы и арки, монолиты и обелиски со светящимися рунами,
  рогатые шпили Нижнего мира, вулканы с лавовыми ручьями, парящие острова
  Пустоты. Кровь и ошмётки остаются на стенах; копоть от взрыва — пятно, которое
  повторный взрыв в том же месте обновляет, а не темнит, и через полминуты оно
  тает. Оружие на полу светится: тёплый свет, отсвет на полу, блик по стволу.
  Всё, что можно подобрать, тоже подсвечено своим цветом: аптечки — красным,
  броня — цветом жилета, патроны — тёплым, батареи — голубым.
  Огонь, которому не к чему крепиться (в небе Измерения Древних), парит без
  держателя.
- **Окна, вентиляторы и ниши:** в высоких залах — большие арочные окна с каменной
  аркой из клиньев, средником и розеткой; за ними по теме уровня ночь со звёздами
  и луной, янтарный или синий витраж, адское зарево Нижнего мира (витражи и
  зарево светятся и бросают свет в зал). На базе — вентиляторы в стенах,
  лопасти крутятся. Вдоль полов каменных залов — глухие арки-ниши: в замке
  доспехи, в склепе урны и черепа, в рунных храмах таблички, в Нижнем мире свечи.
- **Интерьер по темам** (`js/interior.js`): у каждой темы свои крупные вещи, и
  в кадре они не повторяются — одинаковые держатся далеко друг от друга.
  - База: пульты с бегущими строками на экранах, стены мониторов с графиками,
    баки-генераторы с манометром и сигнальной лампой, ящики штабелем, бочки,
    шкафчики, электрощиты с жгутами кабелей, таблички «опасно» и номера секторов
    краской по трафарету.
  - Замок: гобелены с гербом, щиты со скрещёнными мечами, книжные шкафы, стойки
    с оружием, камины и жаровни с живым огнём, люстры со свечами, окна-розы,
    ковровые дорожки.
  - Склеп: колумбарии с нишами, оссуарии из черепов, саркофаги (у некоторых
    сдвинута крышка), свечи, кости, люстры с черепом.
  - Рунные храмы: светящиеся магические печати, друзы кристаллов, синие гобелены
    и дорожки, синее пламя в жаровнях, витражные розы.
  - Нижний мир и Древние: трещины с пульсирующей лавой, барельефы демонов с
    тлеющими глазами, наросты плоти, жаровни, адские розы, кости.
  - Пещеры: сталагмиты, светящиеся кристаллы и грибы.

  Стены изношены: потёки из-под потолка, мох у пола, ржавчина на базе, выбитые
  кирпичи. Высокие залы делит пояс на высоте пяти клеток — утопленная бороздка,
  а не выступ, чтобы её не приняли за уступ. Всё, что светится, даёт свет в зал.
- **Архитектура и атмосфера в духе Quake:** в каждом помещении цоколь вдоль
  пола и фриз под потолком (на базе — металлические панели и кабель-каналы, в
  склепах — ряд черепов), колонны и пилястры с ровным шагом, стальные балки и
  стойки на базе, деревянные стропила в замке и склепах, клетки со скелетами на
  цепях, прикованные к стенам скелеты, шипы, полосы «осторожно» у краёв ям,
  лампы-полосы, которые изредка мигают. Сквозь проёмы в потолке и окна падают
  косые столбы света с пылинками; над лавой дрожит светящаяся дымка и летят
  искры, над слизью и Пустотой стелется туман, со сталактитов капает, из
  решёток на базе идёт пар. Края кадра мягко затемнены.
- **Передний план с глубиной:** между героем и зрителем — тёмные силуэты в цвете
  темы: цепи, клетки со скелетами, знамёна, корни, сталактиты, рога, балки,
  кабели, лампы базы, фонари замка, мясные крюки и черепа на верёвке, а совсем
  близко — редкие колонны во весь кадр (каменная кладка, стальной двутавр с
  полосами «осторожно» и сигнальным огнём, неровный каменный столб в пещерах). Каждая вещь привязана к потолку
  мира и смещается от центра кадра быстрее мира — по горизонтали и по вертикали:
  на бегу обгоняет стены, а в прыжке уходит вниз, как близкий предмет, и не
  прыгает вместе с героем. Слоёв три: средний (×1,22), ближний (×1,55, крупнее и
  чуть размыт, как вне фокуса, свисает из-за верхнего края кадра) и колонны
  (×1,8, с мягкими краями). Правила, чтобы красота не мешала бою: висящее живёт
  над головой героя и растворяется, опускаясь к ней; вещь, которая закрывает
  героя, прицел или монстра рядом, становится полупрозрачной; колонна видна,
  только пока камера в её комнате; в бою весь слой становится прозрачнее; под
  открытым небом и в Пустоте вещей нет. Вещи висят группами (клетка рядом с
  цепью, пара знамён, гроздь сталактитов), длинное — только в высоких залах, и
  ничто не опускается ниже четырёх клеток над полом. Лампы и фонари светятся сами
  и мигают по строкам яркости, как свет в Quake (у неисправной лампы — мерцание
  дневного света); на каменных колоннах изредка горит факел. Всё, что висит,
  раскачивается от взрывов, от тряски (босс, обвал) и от снаряда, пролетевшего
  рядом, а металл при этом звякает; контур подсвечен там, где светло (у лавы,
  факелов, ламп). Слой выключается в настройках: «Передний план».
- **Звук:** все эффекты синтезированы Web Audio. Музыка — мрачный эмбиент со
  своим характером у каждого эпизода: механический гул и лязг базы, колокола и
  хор Чёрной Магии, тритоны и сердцебиение Нижнего мира, холодное мерцание
  Пустоты. Когда рядом встревоженные монстры, вступает боевой слой — ритм со
  своим рисунком на эпизод (бит, там-тамы, пульс, глубокие удары с арпеджио), а
  после боя он затихает. У каждого уровня своя звуковая среда: трещат факелы,
  булькает лава и слизь, плещется вода, гудят машины и лампы базы, поют слипгейты
  и Пустота, звенят капли со сталактитов. Слышны восемь ближайших источников —
  громкость падает с расстоянием, звук идёт с той стороны, где источник. Эхо
  зависит от помещения: в тесном коридоре короткое, в огромном зале долгое, а под
  открытым небом почти пропадает и слышен ветер. Под водой все звуки глухие.
- **Отдача:** попадание по монстру отмечается щелчком и метками у прицела
  (убийство — громче и крупнее), мощный удар на долю секунды останавливает мир
  (30–75 мс). У ствола вспыхивает пламя, дробовики выбрасывают гильзы, которые
  скачут по полу. Монстры перед атакой выдают себя: у солдат и карателей
  загорается дуло, у огра — гранатомёт, у скрагов, воров и шамблера светятся
  глаза или руки, у рыцарей и псов сверкает клинок или пасть — есть доля секунды,
  чтобы увернуться.

  **Секретные уровни** — в каждом эпизоде за тайной стеной обычного уровня спрятан
  красный слипгейт. Он ведёт на короткий необычный уровень, а его выход возвращает в
  эпизод — на уровень после того, где нашли тайник. В меню выбора уровня секретный
  уровень появляется, когда его нашли.
  - E1M7 «Головокружение» (вход — в конце нижнего зала E1M2) — тяжесть вдвое
    меньше: парящие плиты над лавовым морем и зиккурат, на ступени которого без
    этого не запрыгнуть; пульт на вершине открывает решётку у выхода
  - E2M7 «Зал палачей» (из восточного конца нижнего зала E2M3) — только топор:
    остальное оружие вернётся на выходе, а по пути лежат четверной урон и пентаграмма
  - E3M7 «Арена Нижнего мира» (за серебряным ключом в E3M3) — пять волн монстров;
    после каждой телепортируются припасы, после последней открывается слипгейт
  - E4M7 «Тёмная сторона» (у нижней остановки лифта в E4M3) — почти без света:
    у героя фонарь, светятся только провалы в Пустоту и редкие факелы

## Редактор уровней

Уровни — это ASCII-карты в `js/levels.js`, один символ = тайл 16×16. Сам файл
собирается генератором `tools/levelgen/` (помощники рисуют залы, колонны, арки,
засады и тайники), поэтому правьте описания уровней там и перегенерируйте:

```bash
npm run levels                                  # перезаписать js/levels.js
python3 tools/levelgen/build_levels.py --check  # js/levels.js совпадает с генератором?
```

Легенда символов одна и та же для генератора и готовых карт.

| Символ | Значение | Символ | Значение |
|---|---|---|---|
| `#` `%` | стена (два вида текстуры) | `P` | старт игрока |
| `-` | платформа (запрыгнуть снизу, S — спрыгнуть) | `E` | слипгейт-выход |
| `~` `;` `!` | вода, слизь, лава | `>` `<` | вход и выход телепорта (пары по порядку) |
| `,` | открытое небо | `L` `*` | факел, лампа |
| `D` | дверь | `b` | кнопка (открывает ближайшую решётку `=`) |
| `[` `]` | дверь под серебряный / золотой ключ | `(` `)` | серебряный / золотой ключ |
| `=` | решётка | `x` | взрывающийся ящик |
| `$` | тайник (комната за ним скрыта, пока его не откроют) | `@` | электрод (уровень с боссом) |
| `_` | лифт: горизонтальный отрезок — платформа | `:` | куда едет лифт (тот же столбец или ряд) |
| `&` | контрольная точка | `^` | прыжковая площадка |
| `\|` | давилка: связный блок клеток падает до пола | `.` | бездна (мгновенная гибель) |
| `I` | фоновая архитектура: колонны, арки, опоры (не мешает движению) | `Z` | секретный слипгейт (на уровень из `secretNext`) |

Предметы: `+` аптечка 15, `H` аптечка 25, `M` мегаздоровье, `A` `Y` `R` броня,
`U` патроны, `N` гвозди, `K` ракеты, `C` батареи, `Q` четверной урон,
`X` пентаграмма, `V` кольцо теней, `W` биокостюм, `3`–`9` оружие.

Монстры: `g` солдат, `d` пёс, `e` каратель, `k` рыцарь, `o` огр, `z` зомби,
`f` изверг, `s` скраг, `n` рыцарь смерти, `v` ворог, `t` порождение,
`m` шамблер, `a` гаргулья, `r` скорпион, `u` угорь (только в воде),
`c` Хтон, `w` Шуб-Ниггурат, `h` Вестник Бездны, `y` кристалл щита Вестника,
`p` фантом, `q` страж, `j` Древний.

Параметры уровня (поля объекта в `js/levels.js`): `episode`, `next`, `theme`
(`base`, `castle`, `crypt`, `cave`, `elder`, `rune`, `nether`, `void`), `skyTheme` — небо
другой темы, `finale` — текст концовки после уровня, `bossButtons` — кнопки
заряжают электроды Хтона, `bossIntro` — `[x0, y0, x1, y1]`: войдя сюда, герой
видит появление босса, `flood` — `[x0, x1, ряд]`: где поднимается лава Хтона, `altarButtons` — кнопки становятся алтарями рун (зажигаются
касанием и держат барьер Древнего), `exitAfterBoss` — выход появляется только
после гибели босса, `secretNext` — куда ведёт секретный слипгейт `Z`, `secret` —
секретный уровень (в меню появляется, когда его нашли), `gravity` — множитель
тяжести (0,5 — вдвое легче; проверка карт учитывает и прыжки выше и дальше),
`axeOnly` — на уровне только топор (остальное оружие вернётся на выходе), `dark` и
`ambient` — тёмный уровень и доля рассеянного света, `waves` — арена волн:
`{at: [x0, y0, x1, y1], msg, list: [{spawn: [[x, y, 'символ'], ...], drop: [[x, y, 'предмет'], ...], msg}, ...]}`
(вход в прямоугольник будит арену, следующая волна — когда перебита прежняя, `drop`
появляется после волны), `traps` — засады: список
`{at: [x0, y0, x1, y1], spawn: [[x, y, 'символ монстра'], ...], msg}`; когда герой
входит в прямоугольник, монстры телепортируются на указанные клетки (на лёгком
уровне сложности — каждый третий пропускается).

Герой занимает две клетки в высоту, прыгает на 3 клетки вверх и на 4–5 в сторону.
Проверка карт ищет и ловушки: места, куда можно попасть, но откуда уже не дойти
до выхода. Генератор не даст поставить тайник, комната за которым видна с уровня,
и сам кладёт аптечку в тайник без лечения. После правки проверьте карты:

```bash
node tools/check-levels.js            # все уровни
node tools/check-levels.js --map e1m2 --show   # карта с отметками достижимых клеток
```

Скрипт проверяет ширину строк, символы, наличие старта и выхода и то, что
выход (и все алтари) достижимы с учётом прыжков, плавания, ключей, кнопок,
телепортов, лифтов и прыжковых площадок, а в бездну и лаву путь не ведёт.
Для засад он проверяет, что зона достижима, а монстры помещаются, стоят на опоре
и не появляются вплотную к герою.
Он же следит за снабжением: оружие из стартового набора уровня (поле `kit`) должно
встречаться раньше в эпизоде — в наборе или на карте предыдущего уровня.

## Разработка и тесты

Для тестов нужны Node.js 18+ и Python 3. Один раз поставьте Playwright и браузер:

```bash
npm install
npx playwright install chromium
```

```bash
npm test                    # всё: карты, генератор, браузерные тесты (~3 минуты)
npm run test:levels         # только проверка карт и генератора (секунды)
node tests/run.js soak      # один браузерный тест по части имени файла
```

Браузерные тесты запускают игру в Chromium и проверяют её изнутри:

| Тест | Что проверяет |
|---|---|
| `soak` | каждый из 29 уровней минуту играется случайными нажатиями без ошибок и NaN |
| `balance` | нормы баланса обычных уровней (см. ниже), ни один монстр не появляется в стене |
| `cellars` | из каждого погреба под люком можно выбраться: с площадки через люк на пол |
| `traps` | засады срабатывают один раз, на «Лёгком» монстров меньше, никто не появляется в стене |
| `supply` | ключи и оружие переживают гибель, пропущенное оружие ждёт у входа, патронов не меньше минимума и нет куч у старта, рюкзаки при голоде |
| `swim` | затопленную выработку E3M2 можно проплыть с ключом и не захлебнуться |
| `episode4` | пустота, фантом, щит стража; финал: появление Древнего, алтари удержанием, барьер, вытягивание рун, ярость, гибель и выход; переход E3 → E4 |
| `touch` | все уровни запекаются на телефоне, касание включает сенсорное управление; на экране с плотностью 2 настоящее касание попадает в кнопку прыжка и в ячейку оружия; левый стик ведёт героя, вверх — прыжок, вбок — нет; правый стик целится и стреляет; автоприцел доводит на монстра |
| `build` | однофайловая сборка играется без внешних файлов |
| `controls` | переназначение клавиш сохраняется и работает, геймпад (стик, прицел, A, Start), «Продолжить» и рекорды |
| `ai` | на тестовых картах: обход по следу, прыжок через провал, уворот, упреждение, дистанция стрелка, огонь сквозь своих, выстрел не слышен сквозь стену, но слышен через проход, урон будит, потерявший героя монстр успокаивается |
| `visual` | картинки предметов, строка состояния во всех состояниях героя, вспышки чисел, настройка яркости |
| `bosses` | босс есть на всех сложностях, здоровье Вестника и Древнего растёт со сложностью; весь финал E4M6 на «Лёгком»; отладочная панель; появление Хтона, Шуб-Ниггурат и Вестника; электроды по одному не ранят, лава поднимается и не достаёт на уступах; кровь отродий открывает телепорт, щупальца; рывок и гроза Вестника; гибель в замедлении и выход; сцена гибели Хтона — камера у озера, табличка, подсказка после сцены |
| `secrets` | секретный слипгейт за тайной стеной в каждом эпизоде, переход на секретный уровень и возврат в эпизод, меню; половинная тяжесть, топор и возврат оружия, пять волн и выход, тьма и фонарь |
| `start` | хаб: у каждых врат своя сложность и подпись, выше — сложнее; бег с прыжками по первому этажу ведёт к лёгким вратам, подъём по лестнице во дворе — к нормальным и сложным |
| `foreground` | передний план: в прыжке вещь уходит вниз в k раз сильнее камеры, а не вместе с героем; над героем прозрачна; взрыв, тряска и пролетевший снаряд раскачивают, металл звякает; в бою слой прозрачнее; лампы светятся; у тем свои вещи, длинное только в высоких залах, ничто не ниже четырёх клеток над полом; переключатель в настройках; нет вещей под небом и в Пустоте |
| `ring` | кольцо теней: спокойный монстр не замечает героя вплотную; погоня обрывается; на шум монстр приходит, но не стреляет; раненый бьёт по месту выстрела и не следит; шар вора не наводится; без кольца та же погоня попадает |
| `spawns` | точки появления монстров карты, засад и волн не в стене и не в лаве; расталкивание не вдавливает в стену и не сталкивает прыгающего в лаву; живая игра на уровнях с лавой и кислотой — никто не попадает в стену и не заходит в жидкость сам; кочки над кислотой E1M1; слуги боссов |
| `feel` | отметка попадания и стоп-кадр, вспышка и гильзы, подготовка атаки; фоновые звуки уровней, эхо по помещению, звук под водой, тишина на паузе |
| `lifts` | каждый лифт едет, когда на него встали; каждый пульт вызывает лифт касанием, выстрел по пульту тоже; где пульта нет, лифт приезжает сам |
| `polish` | тайники спрятаны: свет, пламя и слипгейт закрытой комнаты не видны, после открытия свет зажигается; в тайниках есть лечение; оружие светится; копоть не копится и тает; значок супергвоздомёта неподвижен; факелы E4 на колоннах; арена Вестника: трамплины с обеих сторон, аптечки, мегааптечка в тайнике; окна и вентиляторы по темам |
| `atmosphere` | силуэты есть у каждой темы неба, горизонт внутри карты, столбы света, дымка над лавой и силуэты переднего плана, музыка эпизода и боевой слой в бою |
| `difficulty` | кривая сложности: дуэли бота с монстрами (случайность с зерном) — урон растёт ровными ступенями «Лёгкий» < «Нормальный» < «Сложный» < «Кошмар», солдат на «Кошмаре» не опаснее вдвое; боль у любого монстра пропускает не больше чем в 1,2 раза больше атак; бой с боссом на «Кошмаре» не дороже 1,9 «Нормального» |

Нормы баланса обычных уровней на нормальной сложности (тест `balance`):

- урон всех патронов уровня, включая выпадающие из монстров, — не меньше 1,3 от
  суммарного здоровья монстров вместе с засадами (сейчас 1,42–9,6);
- лечения — не меньше 4,4 единицы на 100 единиц здоровья монстров (сейчас от 4,6);
- хотя бы два тайника (сейчас 2–4).

Добавлять снабжение в генераторе удобно помощником `add_near(m, x, y, 'KU')`: он
кладёт предметы на тот же пол рядом с точкой, не проходя сквозь стены и ямы.
Куч у старта нет: патроны и лишние аптечки в 16 клетках от старта переносятся на
маршрут таблицей `tools/levelgen/supply_moves.py` — её строит
`tools/dev/spread-supplies.js` (по картам без переносов: сначала очистите таблицу
и перегенерируйте). Тест `supply` следит, чтобы у старта лежало не больше одной коробки.

Те же проверки запускает GitHub Actions на каждый push в `main` и на каждый PR.
Путь к своему Chromium можно задать переменной `CHROMIUM_PATH`.
